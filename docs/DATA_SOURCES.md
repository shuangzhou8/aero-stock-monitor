# 数据来源

- 链：Base mainnet，chain ID `8453`。
- 主列表筛选：Aero Stocks（tier `50`）与双方已列出且含黄金代币（tier `25`）的池子；黄金池不归为股票。
- 新池与新开启奖励记录：Base 全部官方登记池，不限股票或黄金。
- Sugar 合约：`0x082965f28c1aF8c7e236F8A8909596B01D8C6e72`。
- 初始种子快照：2026-10-31，842 个保存的官方注册池中的 102 个 Stocks 池；运行后重新检查注册表。
- ABI：仅保留读取注册池与代币元数据所需的函数签名。
- `registry.json`：公开池地址、代币、Gauge、工厂、余额、流动性及排放统计。
- `tokens.json`：公开代币地址、精度、名称、分类和报价路由元数据。
- 新池登记与 AERO 奖励开启分别记录。创建时间取链上池数据，发现时间取本机完整注册表校验时间；首次记录以种子快照为基准。后续历史保存在本机 `var/discovery-log.json`，不随源码发布。

前台每条数据展示来源区块和时间。RPC 错误、缺失报价与过期快照分别标记。种子数据用于离线测试和首次启动，不应作为实时数据使用。

仓库不包含本机日志、PID、运行缓存、钱包会话、交易历史或登录信息。
